# 재난별 데이터 조합과 해석

## 메인 시나리오: 극한호우 + 산사태

경북이 실제로 이 조건으로 현장훈련을 실시했다. 문경시 산북면 가좌리와 동로면
수평2리에서 일강우량 80mm, 누적강우량 300mm를 가정했다.

### 확인 순서와 이유

```
1. 산사태 예보단계   — 이미 발효된 경보가 있으면 그것이 가장 강한 신호
2. 기상특보          — 호우주의보·경보 발효 여부
3. 실황 강우         — 현재 내리고 있는가
4. 누적 강우         — 선행 강우가 지반을 이미 적셨는가
5. 도로변 취약구간   — 대피경로가 끊길 수 있는가
```

**누적 강우가 중요하다.** 산사태는 순간 강우량보다 선행 누적 강우에 좌우된다.
같은 시간당 20mm가 건조한 지반과 3일 내린 지반에서 다른 결과를 만든다.

### 해석 주의

**산사태 예보는 시군구 단위다.** "문경시 산사태 주의보"가 문경시 모든 가구의
산사태 확률을 뜻하지 않는다. 특정 마을의 위험도는 지형·경사·취약지역 지정 여부와
결합해야 설명할 수 있다.

**취약지역 지정은 현재 발생이 아니다.** 산사태취약지역 데이터는 사전에 지정된
관리 대상이다. 지금 산사태가 났다는 뜻이 아니다.

**과거 발생 이력도 현재가 아니다.** 반복 발생지 분석과 훈련 시나리오 작성에 쓴다.

## 보조 시나리오: 산불

```
1. 산불위험지수     — 시도·시군 단위 지수와 등급 분포
2. 실황 풍속·풍향   — 확산 방향과 속도의 맥락
3. 실황 습도        — 낮으면 위험 상승
4. 대기질           — 연무 확산 보조 지표
```

### 해석 주의

**산불위험지수는 발생 확률이 아니다.** 기상·임상 조건이 산불이 나기 쉬운
상태인지를 나타낸다. 지수가 낮아도 실화는 발생한다.

**자체 확산 모델을 만들지 않는다.** 풍속·풍향으로 확산 방향을 추정해 제시하면
물리 모델 없이 예측한 것이 된다. 방향의 맥락 정보로만 쓴다.

**산불 이후 산사태를 연결해 볼 수 있다.** 경북은 2025년 산불 이후 산사태 위험지역
238개소를 응급복구했다. 산불과 산사태는 별개가 아니라 연속된 복합재난이다.

## 침수

```
1. 기상특보    — 호우 경보 단계
2. 실황 강우   — 시간당 강우 강도
3. 단기예보    — 향후 추이
```

수위·유량은 한강홍수통제소(HRFCO) 키가 있어야 조회된다. 없으면 강우로만 판단하게
되므로 그 한계를 밝힌다.

**홍수위험지도는 화면 표시만 가능하다.** 공공누리 4유형이라 가공할 수 없다.

## 재난 유형별 대피시설 적합성

**자동 전용하지 않는다.** 원본에 명시된 재난유형만 신뢰한다.

| 시설 종류 | 적합 | 부적합 |
| --- | --- | --- |
| 지진 옥외대피장소 | 지진 | **호우·산불** (야외라 비·연기에 노출) |
| 지진겸용 임시주거시설 | 지진 | 확인 필요 |
| 민방위 대피시설 | 공습 | 침수 시 지하는 위험 |
| 학교·체육관·마을회관 | 호우·산불 | 침수 이력 확인 필요 |
| 무더위·한파 쉼터 | 폭염·한파 | 재난 대피용 아님 |

지하 시설을 침수 상황의 대피소로 제시하는 것은 특히 위험하다.

## 값 해석 참고

### 기상청 강수형태(PTY)

| 코드 | 의미 |
| --- | --- |
| 0 | 없음 |
| 1 | 비 |
| 2 | 비/눈 |
| 3 | 눈 |
| 4 | 소나기 |
| 5~7 | 빗방울·눈날림 |

`0`은 결측이 아니라 **강수 없음**이다.

### 강수량 특수 표기

`강수없음`은 0으로, `1mm 미만`은 0.5로 해석한다. 문자열을 그대로 숫자 변환하면
실패한다.

### 특보 단계

| 표기 | 정규화 |
| --- | --- |
| 예비특보 | info |
| 주의보 | advisory |
| 경보 | warning |
| 심각·위험 | emergency |

**"해제"가 붙으면 위험이 종료된 것이다.** `action`이 `cancelled`이면 발효 중이
아니다.

### 산불위험지수 등급

| 지수 | 등급 |
| --- | --- |
| 0~50 | 낮음 |
| 51~65 | 다소높음 |
| 66~85 | 높음 |
| 86~ | 매우높음 |

## 인구 데이터

집계 통계로 **지역 단위 취약성**만 판단한다.

쓸 수 있는 것:

- 예상 대피 인원 규모
- 고령인구 비율이 높은 지역 식별
- 대피소 수용량과의 비교

쓸 수 없는 것:

- 특정 주민의 보행 곤란 여부
- 특정 주민의 장애·질병 추정
- 개인별 이동 지원 필요 판단

개인별 지원 필요 여부는 기관의 주민 명부에서 확인한다. 공개 데이터에 없다.
