# 데이터 원천별 취득 방법과 함정

실제 호출·다운로드로 확인한 내용이다. 조사 원본은
[jxkr2026-datasets](https://github.com/jxkr2026algorix/jxkr2026-datasets)에 있다.

## 인증 정보

| 환경변수 | 발급 | 리드타임 |
| --- | --- | --- |
| `GBSAFE_DATA_GO_KR_SERVICE_KEY` | data.go.kr 마이페이지 > 인증키 발급현황 | 활성화 최대 1시간 |
| `GBSAFE_KMA_APIHUB_AUTH_KEY` | apihub.kma.go.kr 가입 | 즉시 (휴대전화 인증) |
| `GBSAFE_HRFCO_SERVICE_KEY` | hrfco.go.kr | 이메일 승인 클릭 1회 |
| `GBSAFE_SAFETYDATA_SERVICE_KEY` | safetydata.go.kr | 이용신청 후 승인 |
| `GBSAFE_SAFEMAP_API_KEY` | safemap.go.kr | 도메인 고정 발급 (변경 불가) |
| `GBSAFE_ITS_API_KEY` | its.go.kr | 오픈API 신청 |
| `GBSAFE_VWORLD_API_KEY` | vworld.kr | 인증키 발급 |
| `GBSAFE_SGIS_CONSUMER_KEY` / `_SECRET` | sgis.kostat.go.kr | ONE-ID 로그인 후 |

**`DATA_GO_KR_SERVICE_KEY` 하나로 9종 커넥터가 동작한다.** 나머지는 선택이며, 없으면 해당 커넥터가 `not_authorized`로 보고된다.

HRFCO는 네이버·다음·Gmail로 승인 메일이 안 갈 수 있어 기관·회사 메일이 안전하다. 생활안전지도는 발급 시 등록한 도메인을 이후 변경할 수 없다.

## 연동된 커넥터

### 기상청 (15084084, 15000415)

| 커넥터 | 오퍼레이션 | 갱신 |
| --- | --- | --- |
| `weather_now` | `getUltraSrtNcst` | 매시 정시 (40분 이후 조회 가능) |
| `weather_forecast` | `getVilageFcst` | 02·05·08·11·14·17·20·23시 |
| `weather_warning` | `getWthrWrnList` | 수시 |

**격자 좌표가 필수다.** 위경도를 받지 않는다. `gbsafe region <시군>`으로 변환하거나 `regions.to_kma_grid()`를 쓴다.

잘못된 격자를 넣어도 **API는 200과 그럴듯한 값을 반환한다.** 다른 도시의 날씨를 읽으면서 성공한 것처럼 보인다.

**특보는 발표관서 번호로 온다.** 지역명이 아니다.

| 번호 | 관서 |
| --- | --- |
| 143 | 대구지방기상청 (대구·경북) |
| 136 | 안동기상대 (경북 북부내륙) |
| 138 | 포항기상대 (경북 동해안) |
| 108 | 기상청 본청 (전국) |

필터하지 않으면 전국 특보가 경북 특보처럼 섞인다. 실제 조회에서 100건 중 83건이 타 지역이었다. 커넥터가 기본으로 경북 관할만 남긴다.

**통보문 이력에서 현재 상태를 재구성한다.** 이 API는 발효 중인 특보 목록이 아니라 **통보문 이력**을 준다. 해제 통보문을 그냥 버리면 안 된다 — 해제는 자기 자신뿐 아니라 그것이 해제하는 발표까지 무효로 만든다.

버리기만 했을 때 실제로 일어난 일: 13:10 호우경보 발표 + 20:30 해제 이력에서 발표만 남아 **이미 끝난 경보가 발효 중으로 표시**됐다. 실시간 조회에서는 9건이 발효 중으로 보고됐으나 재구성 후 실제 발효는 2건이었다.

`(발표관서, 특보종류)`가 같으면 같은 사안으로 보고 시간순 마지막 통보문이 상태를 결정한다. 강풍 해제가 호우 발표를 무효로 만들지 않고, 안동기상대의 해제가 대구지방기상청의 발표에 영향을 주지 않는다.

전체 이력이 필요하면 `active_only=False`를 쓴다.

강수량 문자열: `강수없음` → 0, `1mm 미만` → 0.5. 숫자 변환만 하면 실패한다.

### 산림청 산불위험예보 (15084817)

베이스가 다른 산림청 API와 다르다. `/1400377/`이며 `/1400000/`이 아니다.

개발계정 한도 **일 1,000건**. 시도·시군 단위 지수이므로 특정 마을의 발생 확률로 표현하면 안 된다.

등급 구간: 0~50 낮음 / 51~65 다소높음 / 66~85 높음 / 86~ 매우높음.

### 산림청 산사태 3종 (15074800, 15074812, 15074816)

**개발단계가 심의승인, 운영단계가 자동승인인 역방향 구조다.** 조사 대상 중 개발 시작 자체가 막히는 유일한 그룹이므로 가장 먼저 신청해야 한다. 승인 소요기간은 공개되지 않는다.

승인 전에는 403이 반환되고, 커넥터가 그 사실을 사유와 함께 보고한다. **키를 다시 발급받아도 해결되지 않는다.**

대체 수단: 산사태위험지도(FGIS, 기관 사이트 다운로드)와 강우 임계값.

### 응급의료 (15000563)

**XML만 반환한다.** 포맷 파라미터가 없다.

`hvidate`가 실제 갱신 시각이다. 이 값 없이 병상 수를 실시간처럼 표시하면 안 되며, 커넥터가 없을 때 `PARTIAL_RESPONSE` 플래그를 붙인다.

음수 병상 수는 미확인으로 취급한다(원천이 -1로 표기하는 경우가 있다).

개발계정 한도 일 1,000건. 운영단계 활용에는 기관 심의가 필요하다.

행안부 경유판(15153443)보다 이쪽이 낫다 — 원천이 같은데 REST 직접 호출이고 운영단계도 자동승인이다.

### AirKorea (15073861)

개발계정 한도 **일 500건**으로 가장 낮다. 다른 API의 20분의 1이므로 폴링 주기를 따로 잡아야 한다.

간헐적으로 504를 반환한다. 서버 측 일시 오류이고 재시도하면 응답한다 — 커넥터가 지수 백오프로 재시도한다.

`serviceKey`(소문자), `returnType`을 쓴다. `dataTime`에 24시 표기가 나오면 다음 날 00시다.

**공공누리 제3유형(변경금지)** — 가공할 수 없다.

### 파일데이터 (3083902, 15123407)

대피시설과 산사태취약지역이다. 포털 다운로드가 세션에 의존해 자동 취득이 어려우므로, 취득은 사용자가 하고 정규화만 담당한다.

```bash
uv run gbsafe normalize-csv shelters ~/Downloads/대피시설.csv --region 문경
```

**CP949 인코딩이다.** UTF-8로 읽으면 깨진다. `decode_csv()`가 자동 판별하고 `ENCODING_CP949` 플래그를 남긴다.

좌표가 없는 행이 많다. `MISSING_COORDINATES` 플래그가 붙고 공간연산에서 제외된다.

**대피시설의 재난유형은 원본에 명시된 것만 인정한다.** 비어 있으면 자동 배정 대상이 되지 않는다.

## 이번 범위에서 제외한 것

| 항목 | 사유 |
| --- | --- |
| 경찰청 UTIC | 수동 심사 + 고정 IP 등록 필요 |
| 홍수위험지도 SHP | KOGL 제4유형 — 재투영·클리핑 모두 제약, 화면 표시만 가능 |
| 전국 침수흔적도 벡터 | 어떤 공개 경로로도 취득 불가 (WMS 래스터만) |
| 지진 대피시설 2종 | 포털 그리드 0행 — safetydata 경유 필요 |
| 경북 지방도 관리현황 | 전체 1행의 빈 등록물 |
| 국토정보플랫폼 DEM | 전용 대용량 전송 프로그램 필요 |
| 주민등록 인구 4종 | `rdoa.jumin.go.kr`이 포털 서비스키를 인식하지 않음 |

DEM은 SRTM 30m 또는 Copernicus DEM GLO-30으로 대체할 수 있다(둘 다 인증 없이 즉시). 도로망은 OSM으로 대체하되 **ODbL share-alike**를 주의한다.

## 호출 함정 요약

| 함정 | 내용 |
| --- | --- |
| 서비스키 이름 | `ServiceKey` / `serviceKey` 기관마다 다름 |
| 포맷 파라미터 | `dataType` / `returnType` / `_type` / 없음 |
| 오류 전달 | HTTP 200 본문에 `returnReasonCode` 또는 `resultCode` |
| 403의 의미 | 활성화 대기 / 심의 대기 / 미신청 — 셋을 구별해야 함 |
| 호스트 | `apis.data.go.kr` 외에 `apihub.kma.go.kr`, `rdoa.jumin.go.kr` |
| LINK 유형 | 91건 중 33건은 포털이 카탈로그 역할만 |

`_classify()`가 이 판정을 담당하고, `gbsafe doctor`가 현재 상태를 보여준다.

## 데이터 품질 결함

`uv run gbsafe quality` 또는 `GET /v1/quality`로 확인한다.

| 데이터셋 | 결함 |
| --- | --- |
| 전국 소방용수시설 (15034538) | 5만 건 표기, 실제 199,507행 (4배 과소) |
| 초단기 침수위험 예측알람 (15152508) | 1행 표기, 실제 100행 / CSV 표기, 실제 ZIP |
| 지진 대피시설 (15072620, 15072622) | 그리드 0행 |
| 경북 지방도 (15153591) | 전체 1행 |
| 15013199 | 수정일 2024, 첫 레코드 2018 |
| 외국인 주민 통계 (15140450) | PDF, 자동 수집 불가 |

포털이 신고한 행 수는 **그리드 다운로드 상한(5만)**일 수 있다. 전수가 필요하면 페이지네이션을 끝까지 돌려야 한다.

## 행정구역 변경

**군위군(47720)은 2023-07-01 대구광역시로 편입됐다.** 경북 자료에 남아 있으면 데이터 시점을 확인한다. `gbsafe region 군위군`이 이 사실을 알려준다.
