# 문서용 캡처

[chatgpt.md](../chatgpt.md)의 캡처는 GitHub 첨부(`user-attachments`)로 들어가 있어
이 디렉터리에는 파일이 없다.

레포에 파일로 커밋하고 싶다면 같은 이름으로 넣고 `chatgpt.md`의 `<img src>`를
상대 경로로 바꾸면 된다. 그 편이 GitHub 밖(사내 미러, 오프라인 사본)에서도 보인다.

| 파일명 | 담을 내용 |
| --- | --- |
| `chatgpt-01-developer-mode.png` | 개발자 모드 토글을 켠 화면 |
| `chatgpt-02-create-connector.png` | 커넥터 생성 폼에 이름·주소·No Auth를 채운 상태 |
| `chatgpt-03-tools-scanned.png` | 도구 12개가 잡힌 목록 |
| `chatgpt-04-enable-in-chat.png` | 대화에서 커넥터를 켜는 메뉴 |
| `chatgpt-05-honest-answer.png` | 조회 실패를 "확인 못 함"으로 답하는 장면 |
| `chatgpt-06-good-answer.png` | 호우처럼 자료가 있을 때 단서까지 붙여 답하는 장면 |

캡처에 **인증키나 개인 계정 정보가 찍히지 않도록** 확인하고 넣는다.
